## 추천 전략

### 1. 최고 속도 우선 (실시간 대화)
- **v2 모델 사용** (102MB)
- 예상 TTFB: 0.3-0.4초
- 품질 저하: 약간 있지만 충분히 좋음

### 2. 균형잡힌 선택 (현재)
- **커스텀 v2ProPlus 모델** (165MB)
- 예상 TTFB: 0.6-0.7초
- 품질: 매우 우수

### 3. 최고 품질 우선 (오프라인 생성)
- **v4 모델** (734MB)
- 예상 TTFB: 2.0-3.0초
- 품질: 최고급

## 실제 측정 필요

위 수치는 예상값입니다. 실제 성능은:
1. GPU 성능 (현재: CUDA 사용 중)
2. FP16 vs FP32 (현재: is_half=true)
3. 배치 크기
4. 텍스트 길이

에 따라 달라집니다.

## 속도 향상 방법

현재 커스텀 모델(165MB)을 더 빠르게 하려면:

1. ✅ **이미 적용 중:**
   - CUDA 사용
   - FP16 사용 (is_half=true)
   - streaming_mode=3 (fastest)

2. **추가 최적화 가능:**
   - v2 pretrained 모델로 전환 (품질 약간 하락)
   - batch_size 조정
   - text_split_method 최적화

## 결론

**현재 yuzuha 커스텀 모델 (165MB):**
- v1/v2 대비 약 1.7배 느림
- v3/v4 대비 약 4배 빠름
- **균형잡힌 선택**: 품질과 속도의 좋은 중간점

**더 빠르게 하고 싶다면:**
→ v2 pretrained (102MB)로 전환 (품질 약간 희생)

**더 좋은 품질을 원한다면:**
→ v4 모델 (734MB)로 전환 (속도 크게 희생)
